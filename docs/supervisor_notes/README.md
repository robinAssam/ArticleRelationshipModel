# Supervisor Notes

One file per meeting or shared note. Verbatim where possible — paraphrase
loses signal.

## Filename convention

`YYYY-MM-DD_topic.md`

Examples:
- `2026-06-03_kickoff_meeting.md`
- `2026-06-05_annotation_guidelines.md`
- `2026-06-10_feedback_on_lid3_example.md`

## File template

```markdown
# 2026-06-XX — [Topic]

**Present:** [names]
**Channel:** [in person / email / Slack / etc.]

## Notes (verbatim where possible)

- ...

## My interpretation

- ...

## Action items

- [ ] ...
- [ ] ...

## Questions to raise next time

- ...
```

Files in this folder are referenced from `docs/03_decisions_log.md`
when a supervisor note triggers a project-level decision.
